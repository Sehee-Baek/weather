# 오늘의 온도

선택한 지역의 현재 날씨를 어제 같은 시각과 최근 30년의 이맘때 기온에 비교해 설명하는 모바일 웹 앱입니다.

## 실행

인터넷 연결과 Python 3가 필요합니다. 이 폴더에서 다음 명령을 실행한 뒤 브라우저에서 <http://localhost:8000>을 여세요.

```sh
python3 -m http.server 8000
```

브라우저가 JavaScript 모듈을 읽을 수 있도록 `index.html`을 직접 열지 말고 위와 같이 웹 서버로 실행하세요. 스마트폰에서 접속하려면 HTTPS로 호스팅해야 현재 위치 권한을 사용할 수 있습니다. HTTPS를 사용할 수 없어도 지역 검색은 가능합니다. 별도의 API 키는 필요하지 않습니다.

## 데이터와 비교 방법

- [Open-Meteo](https://open-meteo.com/)에서 현재·시간별·일별 예보와 과거 재분석 자료를 가져옵니다. 현재 기온은 어제 같은 시각 무렵의 시간별 기온과 비교합니다. 날씨 자료는 관측값과 다를 수 있습니다.
- 이맘때 기온은 선택한 지역 시간의 현재 연도를 제외한 최근 30개 완결 연도에서 해당 날짜 전후 7일의 일별 최저·최고기온 평균을 계산합니다. 공식 기후평년값이 아닙니다. 비교에 충분한 과거 자료가 없으면 비교를 표시하지 않습니다.
- 지역 검색과 현재 위치의 지역 이름은 [OpenStreetMap Nominatim](https://nominatim.openstreetmap.org/)을 사용합니다. 위치를 사용하면 선택한 좌표가 날씨와 지명 서비스로 전송됩니다.
- 선택한 지역과 해당 날짜의 과거 평균은 브라우저에 저장됩니다. 저장이 불가능해도 앱을 사용할 수 있습니다.
- 무료 서비스의 사용량 제한과 이용 조건은 각 제공자의 정책에 따릅니다.
